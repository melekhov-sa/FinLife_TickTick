# Редизайн дашборда FinLife — бриф для дизайн-сессии

**Дата:** 2026-07-29
**Статус:** бриф согласован, ждём визуал + ТЗ из дизайн-сессии

## Решения брейншторма
- **Направление:** «тихая роскошь» (премиальный минимал).
- **Референс:** TickTick — спокойно, чисто, воздух, один сдержанный акцент, аккуратная типографика, тонкая глубина, «дорогие» медленные микро-анимации.
- **Пилот:** экран Главная (Дашборд). По нему обкатываем язык, затем раскатываем на всё приложение.
- **Допущения:** сохраняем систему тем (свет/тьма + цветовые темы) — всё через токены; акцент (сейчас индиго-виолет) — на усмотрение дизайна (оставить или сместить к спокойному), но токеном. Функциональность/навигацию/состав виджетов не трогаем — меняем визуальный слой.
- **Процесс:** визуал делает внешняя дизайн-сессия («claude design»), возвращает мокапы + ТЗ; правки в код вносит Claude Code.

## Бриф (текст для дизайн-сессии)

**1. Продукт и цель.** FinLife — личное приложение «финансы + продуктивность» (по духу TickTick + бюджет). Ежедневное, в первую очередь на iPhone (standalone PWA). Задача: поднять визуальный язык до «тихой роскоши» с ориентиром на эстетику TickTick — спокойно, чисто, воздух, один сдержанный акцент, аккуратная типографика, тонкая глубина, «дорогие» медленные микро-анимации, ноль визуального шума. Пилот — Главная (Дашборд).

**2. Технические рамки (обязательно — иначе невнедряемо).**
- Next.js 16 (App Router), React 19, Tailwind v4, TypeScript. Дизайн-система — на CSS-переменных.
- Токены темизации: `--app-accent`, `--app-accent-weak`, `--app-card-bg`, `--app-border`, `--t-primary/-secondary/-muted/-faint` и т.п. Всё выражать через токены, работать в светлой И тёмной теме (+ несколько цветовых тем). Индиго-виолет — текущий акцент; предложить оставить или сместить, но токеном.
- iOS PWA, mobile-first: safe-area, оболочка fixed, одноколоночный мобильный вид — главный.
- Шрифты — только самостоятельно хостируемые (офлайн PWA), без внешних CDN. Без тяжёлых библиотек; анимации CSS/Motion, экономно.

**3. Экран и состав (визуальный слой, функции не трогаем).** Заголовок «Главная» + дата. Виджеты: TodayBlock (задачи/привычки/события на сегодня — главный), FinanceBlock (кошельки: обычные/кредиты/накопления, долги, «Фин. результат», долговая нагрузка), ActivityFeed (лента), UpcomingPayments (платежи), WeekEventsCard (события недели), ExpiringSubsCard (подписки/документы), FlashcardsWidget (карточки + прогресс), DigestCard (дайджест), ShoppingWidget (покупки, условно). Раскладка: десктоп 3 колонки `[260 | 1fr | 290]`, мобайл — одна колонка (Today → Finance → Shopping → WeekEvents → Payments → Subs → Flashcards → Digest → Activity). Есть фоновая подсветка по времени суток, pull-to-refresh, анимация появления.

**4. Что нужно на выходе.**
- Токены языка: палитра (свет/тьма), типо-шкала (дисплей + текст, самохостируемые шрифты), сетка/отступы, радиусы, тени/подсветки, длительности/кривые анимаций — как CSS-переменные, совместимые с нашими токенами.
- Редизайн Главной: мокапы мобайл + десктоп; трактовка карточек, иерархия, точечная работа акцента, состояния (загрузка/пусто), микро-движение.
- ТЗ на внедрение: конкретный, по-компонентно упорядоченный список правок (что менять в `globals.css` по токенам, как переоформить каждую карточку) — для внедрения в существующий код.

**5. Не трогаем:** функциональность, навигацию, состав виджетов; свет/тьму и токены; никаких данных-заглушек. Формат: 1 основной язык + опц. 1–2 сдержанные вариации карточек/акцента. Приоритет — мобильный экран.
